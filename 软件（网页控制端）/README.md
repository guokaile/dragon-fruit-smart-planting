# 🐉 北方寒旱火龙果智能种植舱

> 纯前端 + 手机蓝牙直连 Arduino 的智能农业监控系统

## 📱 项目特点

- ✅ **手机直接查看**：打开浏览器即可监控种植舱
- ✅ **蓝牙无线连接**：通过 HM-10 BLE 模块连接 Arduino
- ✅ **全自动控制**：土壤干→自动开雾化器；光照低→自动开补光灯
- ✅ **赛博农业风 UI**：深色科技感 + 绿色植物元素，视觉效果拉满
- ✅ **数字孪生可视化**：大棚动画 + 实时设备状态
- ✅ **环境趋势图表**：温度/湿度/土壤/光照 24 小时趋势
- ✅ **AI 种植助手**：内置常见问题智能回复
- ✅ **零后端**：不需要 Python/服务器/数据库，纯 HTML+CSS+JS

## 🚀 快速开始

### 第一步：在电脑上预览网页

1. 把整个 `dragon-fruit-iot-ble` 文件夹拖到 **Cursor** 里打开
2. 在 Cursor 里右键点击 `index.html` → **Open with Live Server**（如果装了 Live Server 插件）
3. 或者直接用 Chrome 浏览器打开 `index.html` 文件
4. 默认会显示**模拟数据**，可以看到完整的农业风界面

### 第二步：连接真实硬件

> 支持两种连接方式，网页上可以切换：
> - **USB 有线（推荐，零额外成本）**：用 USB 线直接连 Arduino
> - **蓝牙无线（可选）**：需要额外买 HM-10 模块

#### 方式一：USB 有线连接（推荐 ⭐）

**不需要买任何额外模块！** 只需要一根 USB 线（你烧录程序用的那根就行）。

1. 用 USB 线连接 Arduino 和电脑（或手机通过 OTG 线）
2. 网页上选择「🔌 USB 有线」
3. 点击「连接种植舱」→ 在弹窗中选择 Arduino 串口
4. 连接成功，开始接收真实传感器数据

#### 方式二：蓝牙连接（可选）

需要额外购买 HM-10 BLE 模块（~15 元），详见下方说明。

#### 烧录 Arduino 程序

1. 安装 Arduino IDE
2. 安装以下库（Arduino IDE → 工具 → 管理库 → 搜索安装）：
   - `DHT sensor library`（DHT11 驱动）
   - `Adafruit SSD1306`
   - `Adafruit GFX Library`
3. 用 USB 线连接 Arduino 和电脑
4. 打开 `arduino/dragon_fruit_serial.ino`（USB 版，不需要蓝牙模块）
   - 如果有 HM-10 蓝牙模块，用 `arduino/dragon_fruit_ble.ino`
5. 选择正确的**开发板**（Arduino Uno）和**端口**，点击上传

### 第三步：手机端连接

1. 用 **Chrome 浏览器**（安卓手机）或 **Chrome Canary** 打开网页
   - 可以用手机扫码访问，或者把网页文件传到手机本地打开
2. 点击页面顶部的 **"连接种植舱"** 按钮
3. 在弹出的蓝牙设备列表里选择你的 HM-10（通常叫 `HM-10` 或 `MLT-BT05`）
4. 连接成功后，右上角会显示 **"已连接"**，数据变成真实传感器数据

## 🎮 功能说明

### 运行模式

- **全自动模式**：系统根据阈值自动控制设备
- **手动模式**：在网页上手动开关补光灯和雾化器

### 控制阈值

| 参数 | 默认阈值 | 触发动作 |
|------|---------|---------|
| 土壤湿度 | < 50% | 自动开启雾化器 |
| 光照强度 | < 30% | 自动开启补光灯 |
| 空气温度 | > 35°C | 日志告警提示 |

> 阈值可以在网页上拖动滑块实时修改。

### 支持命令

网页和 Arduino 之间通过以下命令通信：

| 命令 | 说明 |
|------|------|
| `READ` | 读取当前传感器数据 |
| `LIGHT_ON` / `LIGHT_OFF` | 开关补光灯 |
| `ATOMIZER_ON` / `ATOMIZER_OFF` | 开关雾化器 |
| `AUTO` / `MANUAL` | 切换自动/手动模式 |

## 🔧 常见问题

### 1. 手机浏览器点击连接没反应？

- 必须使用支持 Web Bluetooth API 的浏览器：**Chrome for Android** 最好
- iPhone 的 Safari 不支持，需要换成 Chrome 或开发微信小程序
- 确保手机蓝牙已开启，并且已经配对/授权位置权限

### 2. 找不到蓝牙设备？

- 检查 HM-10 是否正确供电（红灯常亮）
- 确认 TX/RX 没有接反
- 有些 HM-10 默认名字是 `MLT-BT05` 或 `BT05`，多试几个

### 3. 连接上但数据不对？

- 检查传感器引脚是否和代码里一致
- 土壤湿度和光照的映射范围可能需要根据你的传感器校准
- 打开 Arduino IDE 串口监视器查看原始 JSON 数据

### 4. 想在 iPhone 上用？

由于 iOS Safari 不支持 Web Bluetooth，有两个替代方案：

1. **微信小程序**：我可以用 Taro/UniApp 帮你做一个蓝牙小程序版本
2. **ESP32 方案**：换 ESP32 主板，自带蓝牙 + WiFi，可用微信小程序或 APP
