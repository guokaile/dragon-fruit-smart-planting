# 🐉 火龙果智能种植系统 —— 北方寒旱火龙果智能种植舱

> 创新创业大赛作品：智能农业物联网监控系统（Arduino + 网页控制端，纯前端零后端）

## 🌐 在线体验

👉 **https://<你的GitHub用户名>.github.io/dragon-fruit-smart-planting-system/**

（GitHub Pages 部署。用 Chrome 打开即可看到完整界面和模拟数据；连接真实硬件时，请在电脑上用 USB 或蓝牙连接种植舱）

## 📖 项目简介

- **网页控制端**：手机/电脑浏览器直接监控种植舱 —— 赛博农业风 UI、24 小时环境趋势图表、数字孪生大棚动画、AI 种植助手
- **硬件端**：Arduino 固件，DHT11 温湿度 + 土壤湿度 + 光照传感器，全自动控制雾化器 / 补光灯
- **连接方式**：🔌 USB 串口（推荐，零额外成本）或 📶 HM-10 蓝牙无线连接
- **运行模式**：🤖 全自动（按阈值自动控制）/ ✋ 手动（网页开关设备），阈值可在网页实时调节

## 🚀 快速开始

1. **在线预览**：浏览器打开上面的在线地址（或本地打开 `软件（网页控制端）/index.html`），默认显示模拟数据，可浏览全部界面
2. **烧录固件**：按「烧录程序详细教程（图文版）.md」给 Arduino 烧录对应固件
3. **连接种植舱**：网页上选择「🔌 USB 有线」或「📶 蓝牙」，点击「连接种植舱」即可开始实时监控与自动控制

## 🛠️ 技术栈

- HTML5 + CSS3（渐变 / 毛玻璃 / 动画）
- 原生 JavaScript（无框架）+ Chart.js 图表
- Web Serial API（USB 有线）/ Web Bluetooth API（蓝牙）
- Arduino C++（传感器采集与设备控制）
